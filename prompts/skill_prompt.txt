# 2. Core Logic: Potency vs. Count

Status effects have two independent dimensions. Identify which one
each number refers to BEFORE translating.

| Dimension       | Trigger signals                              | Output form           |
|-----------------|----------------------------------------------|-----------------------|
| **Count** (层数) | keyword `Count` / `回数` / `횟수` / `stacks` | `X层[Tag]层数`        |
| **Potency** (强度)| bare number before effect; `Potency` / `付与` / `부여` | `X级...强度` |

> ⚠️ Bare number **before** a raw term = Potency. (`Inflict 5 Burn` → 5级烧伤强度)
> ⚠️ `Count` **after** a bracketed tag = Count. (`[Burn] Count +3` → [Burn]层数增加3)
